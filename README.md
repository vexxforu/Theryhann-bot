Berbeda dengan `.slotchip` (chip lokal di dalam kartu), **`.slot` benar-benar memakai uang RPG**:
koin dipotong dari `u.rpg.money` di `database/users.json` dan kemenangan dibayarkan kembali.
Karena kartu HTML tidak bisa memanggil balik ke bot, **hasilnya diacak di server** (`lib/slotrpg.js`),
lalu kartu HTML memutar animasi gulungan dan **berhenti tepat di hasil server**.

```
.slot              ← putaran dengan taruhan terakhirmu
.slot 500          ← taruhan sekali pakai
.slot max / .slot min
.slotbet 2500      ← ubah taruhan permanen
.slotinfo          ← peluang, RTP teoritis, statistik milikmu
.slotriwayat 10    ← 10 putaran terakhir (menang/kalah)
```

| Bagian | Detail |
|---|---|
| Rentang taruhan | **50 – 250.000** 💰 per putaran (tangga cepat 50/100/250/500/1k/2,5k/5k/10k/25k) |
| Simbol & bayar 3× | 🍒6 · 🍋10 · 🍇16 · 🔔25 · ⭐45 · 💎90 · **7️⃣250** — 2 simbol sama = balik modal (×1) |
| Bobot dasar | `[26,22,18,14,10,6,4]` — simbol langka dinaikkan bobotnya oleh **luck** RPG (maks +60%) |
| Tersambung ke RPG | peluang = `stat7().luck` (job, skill, permata, relik, buff, dekorasi, musim, prestasi) · hadiah 3× dikalikan bonus `stat7().koin` (rumah & dekorasi, **dibatasi ×1,10**) · tiap putaran memberi **EXP** `expHadiah()` · statistik & riwayat di `r.slot` |
| Keseimbangan | RTP analitis **88,96%** (luck 1) → **93,51%** (bonus koin maks) → **94,20%** (luck 2 + bonus); Monte Carlo **200.000 putaran** cocok dengan analitis (selisih < 1%) dan **selalu < 100%** di semua kombinasi luck/koin → koin RPG tidak inflasi |
| Kartu | gulungan beranimasi, paytable, saldo sebelum/sesudah, riwayat 5 putaran terakhir, saran taruhan berikutnya |

Kode: `lib/slotrpg.js` (mesin murni + kartu HTML) & `features/slotrpg.js` (perintah).
Test: `node scripts/test-slotrpg.js` → **241 PASS / 0 FAIL**.

## 🤖 Game AI Rich (AIRichResponseMessage)

Game yang disajikan sebagai **AI Rich response message** (`richResponseMessage`), bukan pesan teks biasa:

| Game | Perintah | Cara jawab |
|---|---|---|
| 🧠 Kuis pilihan ganda (5 ronde) | `.kuisairich` | ketuk pill `A.`/`B.`/`C.`/`D.` atau ketik hurufnya |
| ✂️ Suit vs bot | `.suitairich` | ketuk pill 🪨/️/📄 |
| ⭕ Tic-tac-toe (papan live) | `.tttairich` | ketuk pill nomor 1-9 |
| 🎮 Menu game | `.gameairich` | ketuk pill nama game |
| 🛑 Berhenti | `.batalairich` | — |

**Yang membuatnya spesial:**

* Soal/papan dirender kaya: `addText` + `addTable` (pilihan) + `addCode` (papan TTT) + `addTip`.
* Jawaban berupa **suggestion pills** (`addSuggest`) yang bisa **diketuk** — ketukan masuk sebagai pesan teks dan dicocokkan sesi game.
* Hasil & langkah berikutnya dipakai **live edit** (`sendEdit`) pada pesan yang **sama**, jadi chat tidak spam. Pesan hanya di-edit, tidak dikirim baru.
* Hadiah menang masuk ke RPG (koin + EXP).
* Sesi disimpan di `lib/gamestore.js` (bukan di file fitur) supaya command dan penjawab jawaban memakai sesi yang sama meski loader memuat fitur dengan cache-buster.

## 💳 Custom Welcome / Goodbye Card

Bot bisa mengirim **kartu gambar** saat member masuk/keluar/naik-turun jabatan — lengkap dengan foto profil, nama, nama grup, dan jumlah member. Digambar murni pakai `jimp` (tanpa ffmpeg, tanpa asset eksternal) jadi aman di Termux.

### Cara pakai cepat (di grup, sebagai admin)

```
.welcome on            # nyalakan sambutan member baru
.goodbye on            # nyalakan kartu member keluar
.welcomecard           # preview kartu sekarang
.settheme grape        # ganti tema gradient (lihat .listtheme)
.setwelcomebg <url>    # latar custom (atau reply gambar)
.setwelcomemode text   # ganti ke mode teks+tombol (lebih ringan)

```

Kartu tetap mengirim caption teks. Kamu bisa custom isinya:

| `{time}` | jam |

## 🎮 Panduan Main RPG (v6 — sistem saling terhubung)

Semua data RPG tersimpan di `database/users.json` pada field `u.rpg`. Setiap subsistem **memengaruhi** subsistem lain lewat statistik turunan **ATK / DEF / LUCK**:

```
Level & EXP ──► membuka lokasi, dungeon, monster
Peralatan   ──► weapon/armor/tool  ┐
Penempaan   ──► +4% per level (+1..+10) ├─► ATK / DEF ─► dungeon, arena, battle
Pet         ──► ATK, LUCK, energi  ┘
Kebun       ──► sayur/buah/gandum ─► bahan craft ramuan & roti
Tambang     ──► besi/emas/berlian ─► crafting + penempaan
Misi harian ──► dihitung otomatis dari aktivitas (hunt/mine/win/dungeon/panen/jual)
Bank        ──► koin aman dari kekalahan + bunga 1%/hari
Prestasi    ──► hadiah koin/EXP/item + gelar + LUCK +1% tiap prestasi
```

### Alur main paling cepat

```
.rpg / .rpgmenu2   → menu RPG lengkap (list interaktif)
.rpgkartu          → kartu profil bergambar
.jelajah hutan     → kumpulkan resource + EXP + koin (6 lokasi)
.peta              → lihat lokasi & syarat level
.belibibit → .tanam → .panen    → kebun (15 menit, bisa .sirami)
.pettelur → .tetaskan → .petmakan / .petlatih   → pet (10 spesies)
.resep → .craft pedang → .equip pedang → .tempa senjata   → perkuat ATK
.toko / .tokoalat / .tokopet / .tokoramuan   → belanja
.dungeoninfo → .masukdungeon gua_kelelawar   → butuh 🗝️ kunci
.misi → .misiklaim semua      → hadiah harian
.arena @user 1000             → duel PvP bertaruh koin
.bank 5000 / .tarikbank       → simpan koin (bunga 1%/hari)
.pencapaian → .klaimpencapaian semua → .setgelar Petualang
.rpgstat / .rpgriwayat / .rpglb   → statistik, log, peringkat
```

### Status karakter

| Status | Fungsi | Cara isi ulang |
|---|---|---|
| ❤️ **HP** | Habis → kalah battle/dungeon, rugi koin | `.heal`, `.makan`, regen 1 HP/4 menit |
| ⚡ **Energi** | Biaya aktivitas, jelajah, dungeon, arena | `.makan`, `.toko kue`, regen 1/2 menit, bonus pet |
| ✨ **EXP** | Naik **level** → HP/energi maks + ATK/DEF | aktivitas, battle, dungeon, misi, prestasi |
| 💰 **Koin** | Beli item, telur pet, kunci dungeon, tempa | jual resource (`.pasarjual`), dungeon, arena, misi |
| ⚔️ **ATK** | Damage di dungeon/arena/battle | level, senjata, tempa, pet |
| 🛡️ **DEF** | Mengurangi damage masuk | level, armor, tempa, pet tertentu |
| 🍀 **LUCK** | Memperbesar loot & koin | pet, item 🗺️ Peta Harta, jumlah prestasi |

### Dungeon (5 tingkat kesulitan)

| Dungeon | Level | Lantai | Energi | Hadiah |
|---|---:|---:|---:|---|
| 🦇 Gua Kelelawar | 3+ | 3 | 30 | 💰 900 + 220 EXP |
| 🌳 Hutan Terlarang | 6+ | 4 | 40 | 💰 2.000 + 480 EXP |
| 🏛️ Reruntuhan Kuno | 9+ | 4 | 50 | 💰 4.200 + 900 EXP |
| 🏔️ Puncak Es | 12+ | 5 | 60 | 💰 7.500 + 1.600 EXP |
| 😈 Istana Iblis | 15+ | 5 | 75 | 💰 15.000 + 3.200 EXP |

Butuh 🗝️ **Kunci Dungeon** (beli `.toko kuncidungeon` atau `.craft kuncidungeon`), HP minimal 40%, dan energi cukup. Boss di lantai terakhir (HP 1,8×, hadiah 2×). Gagal → kehilangan 5% koin.

### Pet (10 spesies, 4 rarity)

`.pettelur` (5.000 koin) → `.tetaskan` (30 menit, atau `.tetaskan instan` 1.000 koin) → pet acak:
Common 55% (🐱🐰🐢) · Rare 28% (🦊🦅🐺) · Epic 13% (🐯🐉) · Legendary 4% (🔥🐲).
Rawat dengan `.petmakan` (+80 EXP) dan `.petlatih` (+60 EXP, peluang skill ⭐ naik). Tiap level pet = ATK +1,2.

### Catatan penting

* Cooldown internal RPG terpisah dari cooldown plugin — sengaja, agar ekonomi game seimbang.
* Regen HP/energi dihitung otomatis tiap status dibaca (`applyRegen`), tanpa cron.
* Reset total: `.rpgreset ya` (atau hapus field `rpg` di `database/users.json`).
* `.transfer` / `.tf` kirim koin ke pemain lain; `.arena` duel dengan taruhan.

## 🔁 Update Tanpa Kehilangan Data

Repo menyertakan `update.sh` (di akar folder). Sekali jalan ia:

1. **Backup** `session/`, `database/`, `media/`, `config.js` ke `backup-<timestamp>/`
2. **Unduh** paket baru (link bawaan di dalam script, atau `bash update.sh <url|file.zip>`)
3. **Menimpa kode** saja — data, login, config, `node_modules/`, dan fitur buatanmu **tidak disentuh**
4. **npm install** otomatis
5. Menyimpan `config.js.baru` sebagai pembanding setting versi baru

```bash
cd ~/therjhann-bot
bash update.sh                      # link bawaan
bash update.sh https://.../bot.zip  # link versi terbaru
bash update.sh ~/bot.zip            # file lokal
```

> Kalau versi baru menambah key `config.js`, config lamamu otomatis **ditambal** oleh
> `lib/config-defaults.js` (key yang sudah ada tidak diubah), jadi bot tetap jalan.

## 🛠️ Troubleshooting

| Masalah | Solusi |
|---|---|
| `Nomor BOT dan OWNER tidak boleh sama!` | Ganti `bot.number` di `config.js` dengan nomor kedua |
| QR tidak muncul | Jalankan ulang `npm start`; kalau pakai pairing: `node index.js --pairing 628xxx` |
| "Gagal menautkan perangkat" saat scan | QR-nya sudah hangus (ganti tiap ±20 detik) → scan QR **terbaru** yang dicetak ulang; perkecil font Termux supaya QR utuh; atau pakai pairing code: `node index.js --pairing 628xxx` |
| Pairing code tidak muncul | Slot *Perangkat Tertaut* penuh (maks 4) → hapus yang tidak dipakai di HP bot; atau `node index.js --logout` lalu ulangi |
| Pairing code tidak muncul | Pastikan `session/` kosong (`node index.js --logout`), lalu coba lagi |
| Koneksi nutup terus | Cek internet; hapus folder `session/` lalu login ulang |
| Tombol/list tidak muncul | Lihat bagian `menuMode` — list hanya tampil di WhatsApp **Android**; pakai `.set menuMode button` |
| Menu jadi teks biasa | Itu **fallback otomatis** karena WA menolak pesan interaktif (versi WA lama). Update WhatsApp kamu |
| AI bilang "sedang sibuk / rate-limit" | Isi `pollinationsToken` / `geminiKey` / `groqKey` di `config.js`, coba lagi beberapa detik |
| Stiker gagal / `ffmpeg belum terpasang` | `pkg install -y ffmpeg libwebp` |
| `Cannot find module ...` | `npm install` ulang; kalau perlu `rm -rf node_modules package-lock.json && npm install` |
| Bot mati saat layar HP mati | Pakai `bash scripts/termux-run.sh` + `termux-wake-lock`, matikan battery optimization Termux |
| `EACCES` / permission error | Jangan pakai `sudo` di Termux; pastikan kamu di dalam folder bot |
| Gambar header menu bikin error/lambat | Biarkan `display.menuImage: ''` (default). Header gambar butuh upload media |
| Nomor bot kena banned | Pakai nomor terpisah & jangan spam. Hapus `session/`, login ulang dengan nomor baru |

Cek kesehatan bot tanpa koneksi WhatsApp:
```bash
node scripts/test-features.js                 # tes command default
node scripts/test-features.js .ping .menu .ai # tes command tertentu
```
